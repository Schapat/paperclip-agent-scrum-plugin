# Screenshot-Platzhalter

Dieses Verzeichnis enthält Screenshots für die Dokumentation.

## Benötigte Screenshots

Nach dem ersten Deployment müssen folgende Screenshots erstellt werden:

### 1. `kanban-empty.png`
- Leeres Kanban-Board nach Initialisierung
- Alle 5 Spalten sichtbar (Backlog, TODO, Development, Review, Done)
- "Neuer Sprint" Button sichtbar

### 2. `kanban-active.png`
- Board während eines aktiven Sprints
- Mindestens 2-3 Tasks pro Spalte
- Verschiedene Prioritäten und Story Points
- Zugewiesene Agents sichtbar

### 3. `agent-panel.png`
- Team Status Widget
- Alle 6 Agents mit Status (Idle/Working/Blocked)
- Aktuelle Tasks pro Agent

### 4. `settings.png`
- Einstellungs-Dialog
- Team-Größe Konfiguration
- WIP-Limits
- Sprint-Einstellungen

### 5. `ticket-detail.png`
- Geöffnetes Ticket-Detail-Panel
- Alle Felder sichtbar (Titel, Beschreibung, Story Points, etc.)
- Kommentar-Historie

### 6. `sprint-metrics.png`
- Sprint Progress Widget
- Burndown Chart
- Velocity-Anzeige

## Naming Convention

```
{component}-{state}.png
```

Beispiele:
- `kanban-empty.png`
- `kanban-active.png`
- `ticket-detail-open.png`
- `settings-team.png`

## Anforderungen

- **Format**: PNG
- **Breite**: 1200px (Retina: 2400px)
- **Kompression**: Optimiert für Web
- **Alt-Text**: Im README definieren

## Platzhalter-Hinweis

Bis echte Screenshots verfügbar sind, enthält die README ASCII-Art Darstellungen der UI-Elemente.
